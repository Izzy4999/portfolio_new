**AISHA Analytics Dashboard** is a full-featured analytics platform built for monitoring and analyzing user engagement with the AISHA AI assistant. It provides real-time visibility into conversations, feedback, user growth, and media interactions across WhatsApp and web channels.

## Monitor User Engagement at a Glance

The Overview Dashboard delivers key performance indicators including total users, active users, new user acquisition, and growth trends. Stakeholders can instantly gauge platform health with lightweight, fast-loading metrics that update on demand.

## Analyze Conversations in Real-Time

A split-pane conversation viewer brings WhatsApp-style chats to life with infinite scroll, deep-linking, and anonymous user support. Administrators can browse recent conversations, open full chat histories, and inspect how the AI assistant responds to user queries—all from a single interface.

## Manage Media and Responses

The dashboard handles rich media natively. Audio messages can be previewed inline or opened in a modal player. Image messages are displayed with thumbnails and full-screen viewing. The media management system ensures no voice note or image goes unreviewed.

## Track Feedback and Engagement

Collect and analyze user feedback through star ratings and engagement metrics. The feedback system captures satisfaction scores, surfaces trends, and helps identify areas where the AI assistant can improve its responses.

## Explore User Queries and Behavior

Query Analytics categorizes top user questions and search patterns, revealing what users care about most. The User Directory provides a flexible, paginated table with multi-parameter filtering and demographic insights for deep audience understanding.

## Key Features

- **Real-Time KPI Dashboard** — Lightweight metrics for total users, active users, growth trends, and media volumes
- **Conversation Analytics** — WhatsApp-style chat viewer with infinite scroll, deep-linking, and full history
- **Media Management** — Inline audio players and image preview modals for rich message content
- **Feedback & Engagement Tracking** — Star ratings, satisfaction trends, and engagement metrics
- **Query Analytics** — Categorized top queries and user question patterns
- **User Directory** — Paginated, filterable user table with demographic breakdowns
- **Date Range Filtering** — Global date filtering synchronized across all analytics pages
- **Data Export** — CSV export capabilities for external analysis
- **Dark/Light Theme** — Full theme support with a cohesive design system
- **JWT Authentication** — Secure login with token refresh and role-based access
