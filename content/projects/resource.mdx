The **Resource Sharing App**, built with **Expo** for the frontend and **Express** with **Prisma ORM** (using **MongoDB**) for the backend, enables efficient file and course management. Key features include:

- **File Upload and Download**: Users can upload and download files seamlessly.
- **Admin Approval**: Admins review and approve uploaded files to maintain quality control.
- **Department Creation**: Admins can organize departments for structured file and course management.
- **Course Creation**: Courses can be created under each department, linking relevant files and materials.

This app ensures streamlined resource sharing and administrative efficiency.
